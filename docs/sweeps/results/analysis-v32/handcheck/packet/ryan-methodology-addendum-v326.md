## Claim receipt versus underlying proposition

R20 remains utterance-level. If a later public message genuinely makes a claim
again, that message is an auditable claim receipt and can be rated `OK` even
when the same fact was stated earlier.

Paper-facing semantic counts use an underlying-proposition **range**:

- Fixed state claims (role and self-alignment) with the same game, speaker, and
  content collapse exactly when their truth verdict agrees.
- Action claims (investigation and protection) collapse exactly only when the
  resolved target, result where applicable, literally stated night, and
  truth-at-utterance agree. Thus a detective's later restatement of the same N1
  result is one proposition represented by multiple receipts.
- A grouped statement naming multiple targets contributes one proposition per
  named target/result, even though it is one sentence or message.
- A nightless action or unresolved target does not prove whether the receipt is
  a repeat. The lower endpoint permits compatible links; the upper endpoint
  keeps those receipts separate. The paper reports the range and the exact
  receipt count rather than guessing.
- A premature claim about a future action and a later supported report are
  distinct because action truth is evaluated at the time of the utterance.
- Ambiguous action receipts are disclosed separately. Because an ambiguous
  receipt may later resolve to an already represented proposition, its lower
  endpoint is not added to the truth-resolved headline range.
